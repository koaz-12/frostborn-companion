# 📦 Carpeta de Imágenes de Ítems de Frostborn

Coloca aquí las imágenes y capturas de los ítems del juego en formato PNG o WEBP con el ID correspondiente.
El sistema las cargará automáticamente en la interfaz. Si un ítem no tiene imagen, se mostrará su icono emoji.

Ejemplos de nombres de archivo:
- `pine_log.png` (Tronco de Pino)
- `planks.png` (Tablas de Pino)
- `pliers.png` (Alicates)
- `fish_glue.png` (Pegamento de Pescado)
- `forged_fasteners.png` (Sujeción Forjada)
- `bone_fastener.png` (Sujeción de Hueso)
- `iron_ingot.png` (Lingote de Hierro)
- `steel_ingot.png` (Lingote de Acero)
- `limestone.png` (Piedra Caliza)
- `stone_blocks.png` (Bloques de Piedra)
- `influencePoints.png` (Puntos de Influencia)
